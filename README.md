This repository contains my notes, laboratory exercises, programming activities, and projects for **CPE010 – Data Structure and Algorithm** at the **Technological Institute of the Philippines, Quezon City**.

I use this repository to practice implementing data structures, solving problems with algorithms, and analyzing time and space complexity.

## 💻 Working with This Repository

Clone the repository:

```bash
git clone https://github.com/Acalacpe/CPE010_CPE21S2-Data-Structure-and-Algorithm.git
cd CPE010_CPE21S2-Data-Structure-and-Algorithm
```

Create a separate folder for each submission, such as `activities/activity-01/`. Include the source files and a short README explaining the problem, how to run the code, and sample input and output. Add time and space complexity analysis when relevant.

Language requirements and setup instructions will be documented with each activity or project.
